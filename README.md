# Portal de asistencia de practicantes — I.E.P. El Nazareno

Este repositorio es únicamente para el portal de asistencia de practicantes y las funciones directamente relacionadas con ellos. El software de gestión escolar —que comenzará por Logística— tendrá otra carpeta y otro repositorio.

## Alcance actual

- Registro y consulta de asistencia de practicantes.
- Gestión de miembros/practicantes vinculada al portal.
- Tareas, calendario, perfil, paneles y reportes relacionados con el uso del portal.
- Backend Spring Boot/Java y frontend React/Vite existentes.
